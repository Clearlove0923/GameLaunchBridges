# 卡拉彼丘启动桥接器

`CalabiyauLaunchBridge.exe` 从最近一次官方成功启动记录中读取经过白名单验证的固定启动参数。它在后台启动安装根目录的官方入口，保留启动器自身创建的右下角托盘图标并持续隐藏主窗口；默认等待 12 秒完成 SDK 初始化后直接运行深层目录中的游戏包装入口 `Calabiyau.exe`，全程不需要用户点击“开始游戏”。桥接器在真正的游戏进程退出前保持自身运行，供 Steam 等外部程序跟踪游戏生命周期，并在结束时关闭自己启动的后台官方入口。

官方入口以高完整性级别运行。为可靠控制其窗口，桥接器会保留普通权限父进程并启动一个高权限工作进程，Windows 可能显示一次 UAC 提示；父进程持续等待工作进程，因此 Steam 跟踪的桥接器生命周期不会中断。

## 使用方法

1. 至少通过官方启动器成功进入游戏一次，以建立登录缓存并留下真实启动记录。
2. 把 `CalabiyauLaunchBridge.exe` 放到官方 `CalabiYau.exe` 所在的安装根目录。
3. 运行桥接器；它会在后台完成 SDK 初始化并直接启动游戏，不需要点击官方启动器的“开始游戏”。
4. 游戏本体出现后，桥接器会持续运行；本体连续消失 3 秒后桥接器退出。

桥接器不会修改官方启动器、游戏本体、ACE、Tenprotect 或配置文件。它只接受最近一次官方记录中完整路径与当前发现结果一致、且参数名属于 `-Channel`、`-Lanuch`、`-AdsPath`、`-dx11`、`-dx12` 白名单的命令。直接运行深层目录中的 EXE 而不带这些参数会提示“登录口令过期”；只补齐参数而没有官方入口提供的 SDK 上下文会提示“未初始化SDK[-12000]”。

## 参数

- `--install-root <目录>`：显式指定安装范围；默认使用桥接器所在目录。
- `--validate` / `--dry-run`：只验证路径发现和配置，不启动任何程序。
- `--attach-only`：只附着到已经运行且完整路径匹配的游戏进程。
- `--startup-timeout-seconds <1-3600>`：覆盖直接启动后等待游戏本体出现的时间，默认 180 秒。
- `--exit-delay-seconds <0-300>`：覆盖游戏消失后的退出防抖，默认 3 秒。
- `--no-dialog`：预留给自动测试和无人值守验证。

Steam 启动选项可使用：

```text
"完整路径\CalabiyauLaunchBridge.exe" %command%
```

桥接器会忽略 `%command%` 展开的原始 Steam 命令尾部，避免它改变安装范围或启动逻辑。

## 可选配置

复制 [`examples/CalabiyauLaunchBridge.json`](examples/CalabiyauLaunchBridge.json) 到桥接器同级，并命名为 `CalabiyauLaunchBridge.json`。它可以覆盖包装入口、后台 SDK 入口、SDK 初始化等待时间、游戏本体文件名、启动参数、排除目录、候选路径优先级、搜索深度、超时和退出防抖。`launcherArguments` 保持 `null` 时自动读取最近一次官方成功记录；只有渠道更新导致记录格式变化时才手动配置。配置中不要保存账号、口令、Cookie、令牌或密码。

默认使用与官方快捷方式相同的普通 ShellExecute 权限上下文；只有确认渠道入口要求显式提权时才把 `runAsAdministrator` 改为 `true`。

## 日志

日志固定写入桥接器同级的 `CalabiyauLaunchBridge-log/CalabiyauLaunchBridge.log`。程序始终使用这一个主要日志文件，并在启动时及长时间运行期间清除超过 7 天的条目。日志包含运行标识、版本、系统与架构、发现候选、启动命令、工作目录、游戏进程变化、退出码、运行时长和完整异常堆栈；敏感参数值会被隐藏。

如果日志目录无法创建或文件无法写入，错误弹窗会显示具体失败原因。

## 构建与验证

```powershell
dotnet run --project .\tests\CalabiyauLaunchBridge.Tests.csproj -c Release
.\build.ps1 -GameExe '游戏本体完整路径\Calabiyau-Win64-Shipping.exe'
.\tests\Test-PublishedBridge.ps1
```

发布产物为 Windows x64、自包含、单文件 `Release/CalabiyauLaunchBridge.exe`。图标由 `tools/ExtractGameIcon.ps1` 从游戏 EXE 的多尺寸图标资源重复提取。

## 当前验证边界

- 2026-10-10 已在标准版真实安装中确认最终启动链：后台启动安装根目录官方入口并等待 SDK 初始化后，直接运行深层包装入口可正常进入游戏，无需点击“开始游戏”，SGuard 反作弊进程正常运行。
- 同日确认单独运行深层包装入口会依次暴露两项前置条件：缺少官方记录参数时提示“登录口令过期”，只有参数但缺少后台 SDK 上下文时提示“未初始化SDK[-12000]”。
- 同日已完成最终桥接器生命周期实机验证：高权限工作进程持续隐藏官方主窗口并保留托盘宿主，游戏本体退出码为 0；退出防抖后，桥接器成功清理托盘图标与后台 SDK 入口，高权限工作进程和普通父桥接器均以 0 退出。默认防抖随后由实测时的 10 秒缩短为 3 秒。
- 标准版与腾讯版已增加固定目录结构测试；本机腾讯版当前只有启动器文件，尚未下载游戏本体。
- 官方启动记录中的 `-Channel`、`-Lanuch`（官方拼写）、`-AdsPath` 与图形参数在两次真实启动中保持一致；桥接器从本机记录读取并在日志中隐藏参数值。
- 腾讯版的真实登录、Tenprotect/ACE 初始化和完整游戏生命周期尚未实机验证。
